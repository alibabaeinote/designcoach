# Ali Babaei Design System

The canonical design-system contract now lives in [docs/design-system.md](docs/design-system.md). It defines the visual foundations, tokens, layout, interaction, accessibility, module interfaces, and change process for the React implementation.

The semantic content contract lives in [docs/site-content-model.md](docs/site-content-model.md). It defines page roles, content entities, section meaning, and the mapping between content and visual modules.

Implementation source of truth: `src/design-tokens.css` for tokens and `src/styles.css` for rendering rules.
